# 1837A - Grasshopper on a Line

この問題の制約によると、１手か２手かでしか解けません。二つのケースに別れています。

## n % k != 0

この場合には、一手で飛べるので、それは最適なんです。

## n % k == 0

この場合には、直接には無理なので、二手で飛べます。$k$はいつも$2$以上なんですから、どんな$k$でも、

$$
1 \cong 1 \mod k
$$

なので、

$$
n + 1 \cong 1 \mod k
$$

最適な方針は、$n+1$の距離を跳ね、$1$の距離戻ればいいです。

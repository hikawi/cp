# 2290F - Value Counters

> 解説により、「$B_x$の値は$x$以外に他の数の位置に関係はない」というヒントがあります。

詳しい例を出そうと思います。

その並べ替えから任意の整数$x$を選びます。これから、$x$の左にある$x$より大きい数字を$L$とします。問題文から与えられた$B_x$というのは、「左にある$x$より小さい整数」と「右にある$x$より大きい整数」の差です。

元々の並べ替えにおいて$x$の位置を$I_x$とします。そうであれば、$x$の左には$I_x-1$個がありながら、$x$の右には$n-I_x$個があります。

$L$とは左にある$x$より大きい個数なんですと、$x$より大きい整数の個数は$n-x$であるから、右にある$x$より大きい個数とは$n-x-L$であります。

同じく、左には、もう$L$の大きいのがあるので、左にある$x$より小さいの個数とは$I_x-1-L$であります。前の$B_x$の方式に、

$$
B_x = (I_x-1-L) - (n-x-L) = I_x-1-L-n+x+L = I_x-n+x-1
$$

こうなると、$I_x$（$x$の位置が他の数字に関係ないので、直接に$B_x$から並び替えに$x$の位置を計算できます。

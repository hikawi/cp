# ABC257B - 1D Pawn

$N$個のマス一行のボード（線でもいい）の上に$K$個のコマがあります。$A_i$とは、$i$番目のコマがマス$A_i$に置かれるということで、二個のコマは同じマスに置かれていません。以下のような操作を$Q$回を行います。

> 左から$L_i$番目のコマを右の一マスに移します。でも、すでに一番右のマスに立っていてもっと右に移るのはできない場合と、そのマスにはもう別のコマがある場合には、何も行いません。

問題文読むと、難易度はそんな高くないはずですね。それに$K \leq N\leq 200$という制約があるので、シミュレートしてもTLEになる可能性も低いと思いますが、双方向マップを利用したら、一回でもできると思います。

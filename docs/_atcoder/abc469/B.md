# ABC469B - Isolated Seats

席行を表す文字列$S$が与えられて、$i$番目の文字が`o`ならば人が座っているということで、`x`ならば人が座っていないということです。$S$の中の全部、人が座っていないと、左に席がないか座っていない席があると、右に席がないか座っていない席がある、という三つの条件を満たす椅子の数を求めるという問題です。

これは以外に簡単ですね、$O(n)$で計算できますが、自分がたった昨日見たC++の機能を利用して、以下の提出になってきました。

```cpp
int n;
string s;
cin >> n >> s;
s = "x" + s + "x";

int c{};
for (const auto it : s | views::slide(3)) {
    if (it[0] == it[1] && it[0] == it[2] && it[0] == 'x')
        c++;
}
cout << c << endl;
```

普通にいうべきもんかく簡単な問題ですが、`ranges`というヘッダがすごく好きだと伝えたいと思います。

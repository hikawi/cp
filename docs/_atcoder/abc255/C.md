# ABC255C - ±1 Operation 1

初項$A$、分差$D$、項数$N$の等差数列$S$が与えられて、整数$X$も与えられて、$X$ともっとも近い数列の要素の差を求めるという問題文です。長くて変な問題文ですけど、これだけでいいと思います。

```plaintext
X A D N
6 2 3 3
```

例の数列が、$S=(2,5,8)$となって、$X$との差はそれぞれ、$(4,1,2)$なので、$1$を出します。もちろん、$N \leq 10^{18}$という条件があるので、普通のように全部の要素との差を求めるのはできません。とはいえ、解説ページには他人から共有した全探検法でも解決できるそうですが、まだ確認しません。等差数列がどの要素も直接計算できるというのと思って、割り算などで最も近い要素がある範囲をすぐ小さくするのできると思います。

例というと、`(6 - 2) / 3 = 1`なので、もっとも近い値は`2 + 1 * 3 = 5`であり、`6-5=1`をすれば結果が出せます。でも、どうやらこの方法がWAになってしまいました。理由はこう、と思っております。

1. $X-A$の引き算。もし、$X=10^{18},A=-10^{18}$なら、$X-A$がオーバフローしてしまい、UBになります。
2. どうやらネガディブ値。もし、$X=5,A=1,D=-2,N=3$なら、$S=(1,-1,-3)$となり、$(X-A)\div D = -2$で、$A - 2D = 5$で、差が$0$となってしまいますが、正解は$4$です。

解説を読むと、二分探索でもいい、直接に計算してもいい、二つの方針がありそうです。二分探索はまだ実装していませんが、直接に計算するのは場合に分けて計算すればよさそうです。

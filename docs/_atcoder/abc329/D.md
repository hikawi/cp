# ABC329D - Election Quick Report

$N$の候補者を$1$から$N$を呼び、$M$の選挙投票があり、投票を読むごとにその時点誰が勝っているのかを出せよという問題文です。

```plaintext
3 7
1 2 2 3 1 3 3
```

正解のは、

```plaintext
1
1
2
2
1
1
3
```

投票ずつ進めば、`1`が開票され、$(1,0,0)$となり、一番目の候補者が勝っているので`1`を出します。それで、以下のように、

- `2`が開票され、$(1,1,0)$となりながら、二人が勝っているので、小さい番号のほうで、`1`を出します。
- `2`が開票され、$(1,2,0)$となり、今は逆転で二番目の候補者が勝っているようになったので、`2`を出します。
- 同じく繰り返す。

投票を開票すると、票数を更新し、再び最大値を求めるというシミュレートすればTLEですね。しかし、問題文によると、開票する時点のステート知る必要はなく、ただ誰が一番だと求めています。それで、どうやってステートを更新しても、最速に最大値を求められるのかの問題になってきました。

C++の`set`ではいいと思います、いつもソート済み状態であり、$i$番目の候補者の票数を更新したいときには、$(n,i)$を削除して、$(n+1,i)$を追加してはいいです。

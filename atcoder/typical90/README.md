# 典型90

星数で難易度が決まっていますので、念の為、以下のノートにまとめました。

- 1⭐️: \<149rate,200pts相当 (灰色)
- 2⭐️: 150~400rate,300pts相当 (灰色)
- 3⭐️: 400~799rate (茶色)
- 4⭐️: 800~1199rate,400pts相当 (緑色)
- 5⭐️: 1200~1599rate,500pts相当 (水色)
- 6⭐️: 1600~1999rate (青色、普通のABCにTop1000に出るのが多くなる)
- 7⭐️: \>2000rate (黄色、ARCに気軽に参加できる)
